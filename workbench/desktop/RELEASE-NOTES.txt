MAGENTIC DEVELOPER — RELEASE NOTES

The package version is in version.json next to this file and in
Apps & features after installation.

0.2.0 — Windows preview, first installable build

What is new
- Installs from Install.cmd into the current user's LocalAppData with a Start
  menu entry and an Apps & features entry. Uninstall.cmd removes the
  application and keeps saved workspaces unless asked to remove them.
- Dark workspace theme with one token sheet; Workflows and work items show the
  current stage, the responsible person or agent, the output state and the
  next action, with source evidence, the original agent output, the editable
  handoff and the approval status side by side.
- Agent Studio: overview and library with a configuration version per agent,
  knowledge and tools, saved test cases bound to that version, and workflow
  assignment. Execution success, automated checks and human review are
  reported separately.
- Zenfluence: read a Jira ticket or Confluence page from the configured
  company project and space and attach a reviewed snapshot to a workflow.
  Reads only; nothing is written to Atlassian.
- First run: when Ollama is not running the chat page says so and lists the
  steps (install, pull the model, refresh). A data folder written by a newer
  version is refused with a clear message instead of being rewritten.

Known limitations
- The package is not code signed; SmartScreen warns on first run.
- Updates are manual: uninstall, then install the new package. Saved
  workspaces are kept.
- Microsoft Edge must be installed; the application window uses it.
- Ollama and model downloads are separate. Cloud providers need your own
  credentials. Email and Jira delivery remain previews.
- Reviewer enrollment is not implemented; a single local owner cannot approve
  their own gated stages.

Reporting a problem
Include the version from version.json, the last lines of
%LOCALAPPDATA%\MagenticDeveloper\data\app.log and error.log, and what you did
before it happened. Do not include API keys or tokens.

Update feed (for a later version)
latest.json, published next to each release:
  { "version": "0.2.0",
    "url": "https://<release host>/Magentic-Developer-0.2.0-Windows.zip",
    "sha256": "<hex digest of the zip>",
    "notes": "https://<release host>/release-notes" }
When the MAGENTIC_UPDATE_FEED setting names such a feed, the launcher reads
it once at start and writes "Update available: x.y.z" or "Up to date" to
app.log. Downloading and installing stay manual in this version: uninstall,
then install the new package; saved workspaces are kept.
